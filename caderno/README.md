# Caderno

Espaço de resolução do aluno — nada daqui entra no site do material.

## Como usar o quadro

1. Rode `npm run quadro`.
2. Abra <http://localhost:4123>. O terminal também mostra o endereço para abrir
   no iPad ou celular na mesma rede Wi-Fi — com Apple Pencil a escrita fica bem
   melhor, e o desenho salva direto aqui no computador.
3. Resolva o exercício escrevendo no quadro. Se quiser, dê um nome no campo do
   canto direito ("lei de ohm exercício 3").
4. Clique em **Salvar para correção** — o PNG é gravado em `caderno/imagens/`
   com data e hora no nome.
5. No Claude Code, peça a correção: `/corrigir` (ou "corrige meu quadro").

Atalhos: `Cmd+Z` desfaz, `Shift+Cmd+Z` refaz, `Cmd+S` salva.

As imagens ficam fora do git (`.gitignore`), então o histórico do repositório
continua só com o material do material.
